# Contributing

This template is intended to serve as a base for new development environments.

---

## 🧠 Guidelines

* Keep the structure aligned with the template specification
* Avoid introducing unnecessary complexity
* Ensure the environment remains reproducible

---

## 📦 Development

* Modify Docker configuration in `image/`
* Update `docker-compose.yml` accordingly
* Adjust the `dev` script if needed

---

## 📌 Goal

Maintain this template as:

* simple
* clear
* easy to extend
